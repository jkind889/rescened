# Rescened 1.0 bug list

Community suggestions marks the completion of the 1.0 release scope. Collect remaining bugs here before starting 2.0.

- [ ] Pinned reviews do not show the album cover. Expected: each pinned review displays its associated album artwork.
- [ ] Investigate local search relevance after observing actual usage. The synthetic [search-quality baseline](benchmarks/search-quality/baseline.json) puts a preferred result first for 1 of 7 preference-bearing queries: four preferred results appear at positions 2–3, and two artist-plus-album queries return no results. Current search sorts matches alphabetically by artist/title and requires the entire query to match a single field. Examples include `Discovery` ranking below `Discovery Live`, `Home` below `Homework`, and `Daft Punk Discovery` returning nothing. This small, deliberately challenging fixture set is not a production accuracy estimate; queries such as `Air` also have ambiguous artist-versus-title intent. **Defer matching or ranking changes until actual usage provides evidence.** Collect concrete examples of the query, expected album, and returned order to assess frequency and impact before choosing a change. Exact-title prioritization and cross-field artist-plus-album matching are candidates to evaluate, not approved fixes.
